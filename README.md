# formul

Documents et formulaires de **TRADE EUROPE** (Monaco) — pages HTML statiques bilingues (FR/EN), imprimables en PDF.

- `index.html` — Formulaire de demande de crédit (bilingue FR/EN, avec aperçu PDF, pièces jointes et protection par mot de passe)
- `formulaire-interne.html` — Formulaire de demande de crédit (version interne, sans protection)
- `profil-institutionnel.html` — **Profil institutionnel — document de présentation** (bilingue FR/EN, structuré et extensible : zones « à compléter », mode modification dans le navigateur, enregistrement local et export PDF)
